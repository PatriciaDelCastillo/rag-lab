# Objetivo del Proyecto

RAG Lab es un laboratorio de aprendizaje orientado a la construcción de un sistema de consulta documental basado en documentos PDF.

El sistema permitirá:

* Cargar documentos PDF.
* Consultar información mediante preguntas.
* Buscar información relevante dentro de los documentos.
* Evolucionar hacia una solución RAG (Retrieval-Augmented Generation).

El objetivo es construir una plataforma que pueda utilizarse tanto para aprendizaje como para documentación empresarial.
